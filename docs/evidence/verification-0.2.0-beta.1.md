# 0.2.0-beta.1 검증 기록

검증일: 2026년 10월 1일. 개발 환경: macOS arm64, Python 3.12.14, pygame-ce 2.5.8, pytest 8.4.2, PyInstaller 6.16.0.

이 문서는 원본 로그와 보고서를 함께 읽는 베타 후보의 검증 기록이다. 외부 테스터의 재미 평가나 Windows 네이티브 실행을 자동 검사의 결과로 대체하지 않는다.

## 최종 자동 검증

전체 자동 검사 **55개가 28.47초에 통과**했다. 기본 전장 검사 결과는 **50개 / 고유 배치 50개 / 연결 정상**이다. 왕국 콘텐츠와 일곱 개발 역할의 입력 계약 검사도 통과했다. 원본은 `beta-tests.txt`, `beta-audit.json`, `beta-audit.log`, `beta-build.txt`이다.

지역 전투와 장기 실행 검사는 28.522초에 끝났다. 고정한 공격 출진 820명·수비 700명 조건에서 지역 전장 50개를 실행해 공격 승리 28회, 수비 승리 22회를 얻었고 가장 긴 전투는 127.6초였다. 이 조건의 관측값이며 모든 병력·장수 조합의 균형을 검증한 승률이 아니다.

시드 742·1304·9102를 각각 480주 진행했다. 세 세계는 각각 누적 전투 316·320·320회를 기록했고 200명·50지역과 유효한 자원·참조 계약을 유지했다. 연대기는 최근 600개만 보존하므로 최근 기록에 남은 전투 수와 누적 수를 구분한다. 마지막 행동 분포도 전체 기간의 행동 빈도를 뜻하지 않는다.

기사 `o024`, 재야 `o180`, 군주 `o000`을 24주 세계에서 선택해 내정·수련·순찰·징병·교류·휴식 및 임관으로 96주를 진행했다. 세 흐름 모두 120주에서 연대기 결말에 도달했고 완료 과업은 각각 3/5·2/5·4/5였다. 이 스크립트의 승전 수는 0이며 수동 공격 지휘의 성취도를 측정한 실험은 아니다.

로컬 제보 ZIP을 실제 `replay_report.py` 명령으로 임시 폴더에 복원해 세계 해시, 1.0초 진행한 전투 전체 데이터, 지역 전장 50개가 일치함을 확인했다. 기존 사용자 저장은 수정하지 않았다. 원본 결과는 `beta-replay.json`이다.

## 실행한 범위

- 생성 계약: 장수 200명, 성 20개, 거점 30개, 연결된 전략 도로와 유효한 참조.
- 같은 시드 재현, 세계와 전투 저장 후 미래 상태 일치, 손상 체크섬 거부와 정상 백업 보존.
- 공격·방어 지휘, 수비측 명령과 철수, 이중 결산 거부와 병력 보존.
- 50개 고유 전장의 출진·중앙 거점 연결, 지형 경로·시야, 도달 불가 명령의 처리.
- 편집기 실행 취소·다시 하기, 검증과 저장, 미저장 변경 확인, 캠페인과 분리된 시험 전투.
- 200개 초상 주소와 서로 다른 픽셀 영역, 전체 화면 렌더와 저장·복원 UI 흐름.
- 지역 전장 50개에서 실제 자동 전투, 세 시드 각각 480주 역사, 세 플레이 역할의 96주 행동 흐름.
- 역사에서 생성한 과업과 연대기 결말, 로컬 제보 파일의 세계·전장 복원.

## Mac 앱 확인

PyInstaller로 이 Mac의 arm64 앱을 만들고 네이티브 창에서 생성 미술, 한글, 메뉴, 전장 편집, 실행 취소와 시험 전투의 마우스 입력을 확인했다. 키 입력 규칙은 PyGame 이벤트 자동 검사에서 확인했다. UI 자동화의 문자 키 전달은 SDL 화면에서 확인되지 않아 이를 네이티브 키보드 검증 통과로 기록하지 않는다.

이전 후보의 산악 전장 시험에서 25초의 부대 이동과 병력 손실을 확인하고 상태 표시 겹침을 수정했다. 이번 평면 지형을 적용한 새 실행 파일에서는 산악과 강의 재질, 격자 버튼의 표시·숨기기를 확인했다. 강 전장 시험을 39초 진행·일시정지해 아군 438/820명·적군 463/780명을 관찰했고, 철수 확인·결과 화면·편집기 복귀를 실제 마우스로 확인했다. 네이티브 키보드 입력은 추가 확인했다고 기록하지 않는다.

Mac 배포 ZIP을 임시 폴더에 풀어 실행 권한과 프레임워크 심볼릭 링크 91개를 확인했다. 압축 해제한 실행기의 doctor·validate-maps 및 편집기·전투 화면의 headless 실행은 모두 종료 코드 0이었다. 지역 전장 50개, 생성 자산 9개와 각 자산 SHA-256도 확인했다. 소스 ZIP은 손상 검사에 통과했고 사용자 저장·제보·가상환경·캐시를 포함하지 않는다. 반복 검사는 `tools/verify_release.py`, 원본 결과는 `beta-package.json`, 최종 ZIP 체크섬은 `releases/SHA256SUMS.txt`다.

편찬본은 18개 장과 내장 삽화 7개를 포함한다. 실제 브라우저에서 모든 삽화 로드와 목차 이동, 가로 넘침이 없는 화면을 확인했다. HTML은 그림을 포함하므로 한 파일로 오프라인에서 읽는다. 원고는 최종 출판 교정·조판 전의 개발 원고다.

## 미확인과 배포 범위

Windows 실행 스크립트와 Windows·Mac CI 구성은 제공한다. 이 작업에서는 Windows 실행 파일과 CI 실제 실행, Intel Mac, 외부 PC의 성능, 운영체제별 키보드·고해상도 화면 조합은 확인하지 않았다. Mac 외부 배포용 서명·공증은 적용하지 않았다.

외부 테스터 플레이, 장편 캠페인의 재미와 밸런스, 전문 미술 교정, 음악·음성, 접근성 전체, 멀티플레이와 전장의 안개는 이번 결과에 포함하지 않는다. 배포 파일의 성격은 클로즈드 베타 후보이며 상용 출시 승인과 구분한다.

## 자연 지형과 원고 구조 갱신

기본 전장 배치를 revision 2로 갱신했으며 형식은 schema 1을 유지했다. 이전 베타의 실제 전장 파일을 docs/examples/battlefield-v1.json에 보존하고, 그 전장으로 저장한 전투의 복원·추가 진행이 일치하는 검사를 추가했다. 편집·되돌리기·표시 크기 변경 시 그림 갱신과 격자 표시 전환의 비변경성도 검사했다. 높이 필드나 고저차 규칙은 추가하지 않았다.

이전 고정 조건의 공격 40승·수비 10승과 최장 141.8초, 각 320회의 역사 전투는 terrain-previous-audit.json의 이전 배치 관측값이다. 현재 배치의 28승·22승과 최장 127.6초, 역사 전투 316·320·320회와 구분한다. 지형 배치가 바뀌었으므로 판세와 과업 결과도 달라졌다.

새 생성 시트 terrain-v2.png 원본을 보존하고 4열·2행 평면 재질을 적용했다. 이미지 출처와 프롬프트를 명세에 남겼으며 editor-river.png 등 실제 화면을 다시 촬영했다. 3장은 실제 OOP 객체 책임·합성·직렬화를, 13장은 실제 개발 에이전트 1개와 역할 계약 7개·도구·게임 AI의 차이를 설명한다. docs/examples/oop_flow.py는 실제 실행해 1주·장수 200명과 데이터 왕복을 확인했다.
