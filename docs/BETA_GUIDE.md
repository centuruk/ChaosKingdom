# 혼돈의 왕국 0.3.0-beta.2 테스터 안내

이 버전은 Mac의 PNG 알파 합성을 수정한 업데이트입니다. 화면의 장식·성벽·다리·부대 뒤에 검은 사각형이 생기는 문제를 수정했습니다. 기존 캠페인 저장 형식은 그대로 사용합니다.

이 빌드는 가상의 중세 장수제 전략 게임을 소규모 플레이 테스트할 수 있게 만든 베타 후보입니다. 200명의 장수, 성 20개, 거점 30개, 지역 전장 50개와 편집기가 있습니다. 장수 AI와 전투는 오프라인으로 실행하며 이미지 생성 API 키가 필요하지 않습니다.

## 실행

Mac용 묶음에는 `ChaosKingdom.app`이 들어 있습니다. 소스 폴더에서는 `launch.command`를 실행합니다. Windows 소스 묶음에서는 Python 3.10 이상을 설치하고 `launch.bat`를 실행합니다. 첫 소스 실행은 pygame-ce를 설치하므로 인터넷이 필요합니다. 이후 게임 플레이는 오프라인입니다.

macOS의 실제 빌드·입력 검증은 검증 보고서에 기록합니다. Windows 실행 스크립트와 CI는 구성되어 있지만 이 Mac에서 Windows 바이너리 실행을 검증한 것으로 간주하지 않습니다. 외부 배포용 서명·공증은 적용하지 않았습니다.

## 첫 30분

1. 새로운 이야기에서 왕관 없는 새벽을 선택하고 역사 생성 뒤 소속 있는 기사·대장으로 시작합니다.
2. 내정과 순찰을 수행하고 장수 교류를 한 번 진행합니다. 지도에서 과업과 역사적 배경을 열어 목표와 생성 근거를 읽습니다.
3. F5로 저장하고 게임을 다시 열어 저장한 이야기를 불러옵니다. 날짜·자금·장수 위치가 같아야 합니다.
4. 전투 연습에서 좌클릭 부대 선택, A 전체 선택, 우클릭 이동·적 공격, Space 정지·재개를 시험합니다. 전진·돌격·방어·우회와 격려를 비교합니다.
5. 캠페인에서 연결된 교전 영지로 진군합니다. 현재 아군 영지가 공격받으면 방어전을 지휘합니다. 전투 중 F5 저장 후 다시 불러오면 부대·지형·시간·명령이 유지되고 일시정지 상태로 시작합니다.
6. 메인 메뉴의 아이소 전장 편집기를 열고 다른 지역을 고릅니다. 지형을 칠하고 Z/Y로 되돌리기·다시 하기를 시험한 뒤 경로를 검증합니다.
7. 성벽은 막고 성문은 통행합니다. 다리를 끊거나 출진 위치를 성벽 위에 놓으면 저장이 거부되어야 합니다. 올바른 지형으로 고친 뒤 저장하고 시험 전투를 수행합니다. 연습 뒤 편집기로 돌아와야 합니다.
8. 최종 목표는 소속 세력으로 성 20개와 거점 30개, 총 50곳을 다스리는 천하통일입니다. 96주마다 중간 연대기를 기록하고 플레이는 계속됩니다.

## 저장과 제보

행동 뒤와 전투 10초마다 자동 저장합니다. 직전 정상 저장은 `campaign.backup.json`에 남습니다. 편집본은 저장 폴더의 `battlefields`에 있고 기본 전장 파일은 보존합니다.

소스 실행의 저장 폴더는 프로젝트의 `saves`입니다. Mac 앱은 사용자 Library의 Application Support/ChaosKingdom, Windows 앱은 LOCALAPPDATA/ChaosKingdom을 사용합니다. `CHAOS_KINGDOM_HOME`으로 별도의 테스트 폴더를 지정할 수 있습니다.

R키로 만든 `reports/beta-report-...zip`은 게임 상태·전장·현재 세션의 최근 명령을 담은 로컬 자료입니다. 자동 전송하지 않습니다. 제보에는 발견 상황, 기대한 결과, 실제 결과, 재현 순서와 ZIP 이름을 적어 주세요. 예기치 못한 예외의 `crash-...json`에는 추적 경로가 들어 있으므로 전달할 파일을 확인합니다.

## 이번 베타의 범위

장편 대사, 약속과 가족 관계, 개별 병사의 충돌, 멀티플레이, 전장의 안개, 전문 음악·음성, 접근성의 모든 기능은 아직 포함하지 않습니다. 기본 초상은 200개이며 표정별 변형은 없습니다. 숲 시야와 바위 지대 엄폐는 규칙화된 표현입니다. 최종 상용 게임의 역사·미술·밸런스 분량을 모두 완성했다는 의미는 아닙니다.

이번 테스트에서 가장 필요한 피드백은 이해하기 어려운 행동 이유, 의미 없는 반복 행동, 모든 상황에서 우월한 전술, 저장 후 달라지는 상태, 지역 지형 때문에 진행이 막히는 사례입니다. 사람이 플레이하며 느끼는 재미와 불편은 자동 검사가 대신할 수 없습니다.

전투는 적 활동 부대 전부 와해 또는 180초의 전황 판정으로 끝납니다. 판정은 활동 병력×(0.4+사기/100)의 합계와 거점 단독 확보 초×2를 더하며 동점이면 수비 승리입니다. 거점 확보만으로 즉시 승리하지 않습니다. 지형 높이·단차는 없으며 아이소 시점과 건축물의 높이만 표현합니다.
