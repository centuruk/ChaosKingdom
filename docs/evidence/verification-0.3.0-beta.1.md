# 0.3.0-beta.1 검증 기록

검증일: 2026년 10월 1일. macOS arm64, Python 3.12.14, pygame-ce 2.5.8, pytest 8.4.2, PyInstaller 6.16.0.

## 자동 검사와 실제 실행

전체 자동 검사 **70개가 58.70초에 통과**했다. 전장 50개·고유 배치 50개·연결 정상이며 왕국 콘텐츠와 실제 에이전트·스킬 명세 검사도 통과했다. 원본은 `isometric-beta-tests.txt`, `isometric-map-validation.json`, `isometric-agent-catalog.txt`이다.

`beta_audit.py`는 59.168초에 지역 전투 50회, 시드 742·1304·9102의 각 480주 역사, 기사·재야·군주의 각 96주 흐름을 완료했다. 모든 전투에서 이동 가능한 칸·병력 보존·전투 종료를 확인했다. 고정 공격 820명·수비 700명에서 공격 35승·수비 15승, 최장 180.2초였다. 이 조건의 관측값이며 모든 조합의 균형이나 외부 테스터 재미 평가를 보증하지 않는다. 각 역사의 누적 전투는 320회였고 200명·50지역·참조와 자원 계약을 유지했다.

기사·재야·군주의 과업은 각각 4/5·3/5·3/5, 승전은 1·0·0이었다. 기사 승전은 스크립트가 대기 방어전을 자동 결산한 결과다. 세 흐름 모두 중간 연대기를 기록하고 최종 outcome 없이 계속 플레이할 수 있었다. 천하통일의 최종 소유 조건·중복 결말 거부·실제 마지막 영지 전투의 점령과 승리 연결은 별도 자동 검사로 확인했다. 장편 통일 캠페인을 사람이 끝까지 완주한 기록은 아니다.

추가 검사는 두 화면 크기의 모든 640칸 투영 왕복·다이아몬드 밖 입력 거부·부대 선택과 이동 입력·성문 편집과 되돌리기·집단 목적지 분산과 겹침 완화·수비 재배치·미달성 인연 목표 생성·건강한 영지 문구·옛 96주 결말 저장의 문장과 난수 보존을 다룬다. 기존 전장 스냅샷과 진행 중 전투의 저장 후 미래 상태 재현 검사도 계속 통과한다.

## 발견과 수정

첫 50전장 검사에서 s01의 59.4초에 창병 중심이 통행 불가 성문 옆 칸 (25,8)에 들어갔다. 부대 회피 뒤 경로 중심에서 벗어난 상태로 다음 지점까지 직진하면서 모서리를 자른 결함이었다. `Battlefield.traversable`로 이동 선분의 모든 격자 구간을 검사하고 막히면 현재 칸 중심으로 복귀하도록 수정했다. 실제 좌표를 회귀 검사에 남겼고 전장 50회 검사를 다시 통과했다.

처음 `.venv/bin/pytest` 직접 호출에서는 프로젝트 import 경로가 없어 수집이 실패했다. `.venv/bin/python -m pytest`로 실행해 최종 결과를 얻었다. 이 실행 오류와 게임 결함을 구분한다.

이전 평면 지형 후보의 55개 검사, 공격 28승·수비 22승·최장 127.6초는 `verification-0.2.0-beta.1.md`와 `isometric-previous-audit.json`에 보존했다. 성곽·성문과 AI·이동이 함께 바뀌었으므로 이번 관측의 차이를 한 원인으로 단정하지 않는다.

## 이미지와 제작 기록

GPT Image Generator를 실제 두 번 호출해 건축물·부대 시트를 제작했다. 각 원본은 1774×887, 4열·2행의 투명 PNG다. 총 생성 원본 11개의 출처·프롬프트·SHA-256을 명세에 보존했고 런타임 주소를 검사했다. 동일하게 나온 성벽 방향 한 개는 명세에 기록한 런타임 좌우 반전으로 맞췄다. 부대 시트에는 요청과 달리 작은 바닥 조각이 있으며 원본 그대로 사용한다.

실제 PyGame의 아이소 전투·성곽·강·다리·편집기·전략 화면을 다시 렌더하고 육안 확인했다. 스킬 `imagegen`은 적용·도구 실행, `superdesign`은 지침 참고로 기록한다. Superdesign CLI·캔버스·모델 비교·업로드는 실행하지 않았다. 실제 개발 에이전트 1개, 역할 계약 7개, 별도 보조 에이전트 실행 없음이다. 원문 경로·해시·용도·산출물은 `docs/production/workflow-tools.json`, 설명은 원고 13장이다.

## 플랫폼과 배포 확인

Mac arm64 앱 빌드는 성공했다. ZIP을 임시 폴더에 풀어 실행 권한·프레임워크 심볼릭 링크 91개·지도 50개·생성 원본 11개와 SHA-256을 확인했다. 압축 해제한 실행기의 doctor·validate-maps·편집기·전투 headless 실행은 모두 종료 코드 0이었다. 소스 ZIP도 CRC 검사와 사용자 저장·제보·가상환경 제외 검사에 통과했다. 원본은 `beta-package.json`이다.

새 앱의 실제 창 검증을 시도했으나 Mac 화면 잠금으로 UI 도구가 앱을 열지 못했다. 사용자에게 수동 해제를 요청했으며, 이 버전의 새 창 마우스·키보드 검증은 미확인이다. `isometric-native-qa.json`에 기록한다.

기존 29주 캠페인의 사본을 새 네이티브 실행 파일의 headless 모드로 불러와 실제 화면을 렌더했다. 주차·장수·영지·과업·난수 데이터 보존과 사용자 원본 파일 SHA-256 불변을 확인했다. 실제 창 입력 검사와 구분하며 `isometric-legacy-save.json`에 기록한다.

편찬본은 18장과 내장 그림 10개다. 실제 브라우저에서 갱신 버전·스킬 명세·모든 그림 로드·가로 넘침 없음·13장 목차 이동을 확인했다. 결과는 `isometric-book-qa.json`이다. 이전 후보의 실제 캠페인 플레이는 `native-play-2026-10-01.md`에 보존하며 이번 실행 기록과 구분한다.

Windows 스크립트와 CI는 제공하지만 Windows 실행 파일·CI 실제 실행·Intel Mac·외부 PC 성능은 미확인이다. 외부 배포용 서명·공증, 외부 플레이테스터 평가, 장편 캠페인 재미와 밸런스, 전문 미술 교정은 완료 범위로 주장하지 않는다.
