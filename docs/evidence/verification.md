# 0.3.0-beta.2 알파 수정 검증

2026년 10월 1일, macOS arm64. 투명 PNG의 검은 사각형을 Cocoa에서 재현하고 App 캔버스에 32비트 SRCALPHA 합성을 명시했다. 이미지 원본과 저장 스키마·전투 및 세계 시뮬레이션은 유지했다.

- 전체 **73개 검사 통과, 60.30초**. 메뉴·전투·편집기 Cocoa 형식 회귀 검사 포함.
- 지도 **50개·고유 배치 50개·연결 정상**.
- 배포 앱의 Cocoa 두 프레임 실행: 메뉴·전투·편집기 모두 종료 0, 완성 프레임 알파 전부 255. 장식 중앙 RGBA는 수정 전 (0,0,0,0), 수정 후 (11,18,19,255).
- 실제 Mac 창에서 v0.3.0-beta.2 메뉴 장식, 일시정지 연습 전투 부대·성벽, s01 성곽과 s10 강 편집기 다리의 배경 보존을 확인했다. 편집본 저장·캠페인 진행은 하지 않았다.
- 최신 사용자 저장의 에버홀드 전투를 표시 74초에서 일시정지 상태로 불러왔다.
- 실제 키보드 입력·전투 완주·Windows 및 Intel Mac 실행은 이번 검증 범위가 아니다.

픽셀 값, 도구와 확인 범위, 조사 중 실패 및 원본 이미지 해시는 [알파 검증 자료](alpha-compositing-qa.json)에 보관한다. 이전 70개 검사, 50전장 전투·480주 역사·역할 실험과 플랫폼 검증은 [0.3.0-beta.1 기록](verification-0.3.0-beta.1.md)에 보존한다. 이번 화면 수정에서 장기 시뮬레이션을 반복 수행했다고 주장하지 않는다.

실제 개발 주체·스킬·플러그인 상태는 `docs/production/workflow-tools.json`과 원고 13장에 갱신했다. 원고 화면은 재촬영했다. Mac 재빌드는 성공했으며 배포 ZIP 검증 결과는 `beta-package.json`에서 해당 버전을 확인한다.
