## 편찬

프로젝트 루트에서 `python tools/build_book.py`를 실행하면 목차·그림·코드·표를 포함한 `docs/book.html`을 생성합니다. HTML은 인터넷 연결 없이 읽을 수 있으며 브라우저 인쇄 기능으로 PDF 저장이 가능합니다. 인쇄용 CSS는 A4 여백과 장별 페이지 나눔을 제공합니다. 이 버전은 편집 가능한 개발 원고이며, 최종 출판 교정이나 전문 조판을 마친 책은 아닙니다.

본문의 “구현했다”는 현재 소스에 존재하는 기능에만 사용합니다. “실험했다”는 실행 근거가 있는 경우에만 사용합니다. 확장 아이디어는 구현 사실과 구분합니다. 테스트 수와 측정치는 검증 결과가 바뀔 때 함께 수정합니다.
